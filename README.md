# 🏮 Ánima · Noche de Cempasúchil

Juego 2D hecho con HTML, CSS y JavaScript puro (Canvas). Eres una luciérnaga en un cementerio la noche de Día de Muertos: tu luz se apaga poco a poco y cada flor de cempasúchil la reaviva.

## Cómo se juega

- Solo ves dentro del círculo de tu propia luz.
- Las sombras solo se ven completas dentro de tu resplandor; fuera de él solo se distinguen sus ojos.
- Si una sombra te toca, pierdes luz. Si la luz llega a cero, pierdes.
- Junta 15 flores para completar la ofrenda. Cada 5 flores sube la noche y las sombras se aceleran.

## Controles

- Teclado: flechas o W, A, S, D.
- Celular: cruceta en pantalla o arrastrar el dedo sobre el juego.

## Cómo jugarlo

Abre `index.html` en tu navegador. No requiere instalación ni dependencias.

## Publicar en GitHub Pages

1. Sube `index.html` y `README.md` a un repositorio.
2. Ve a **Settings → Pages**.
3. En **Source** elige **Deploy from a branch**, la rama `main` y la carpeta `/ (root)`.
4. Guarda. En un par de minutos el juego estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
